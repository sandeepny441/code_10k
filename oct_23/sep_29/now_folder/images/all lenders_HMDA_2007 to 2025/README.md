# All lenders HMDA aggregate package, 2007-2025

This folder contains one Excel workbook per year with aggregate lender-level HMDA counts. Rows are ranked by loans funded within each year.

Columns: Rank, Lender, HQ State, Applications received, Applications approved, Loans funded, Loans funded percentage, Loans funded as a percentage of industry loans funded, and Lender ID.

The package includes all lender rows available in the source year, not a fixed 5,000-row cutoff. Older years have more than 5,000 lenders; recent years have fewer.

The HQ State column uses the best available lender/institution state lookup. For 2018-2025, LEI headquarters-state data is used only where it was already cached; otherwise the HMDA/Fed institution state lookup is used.
