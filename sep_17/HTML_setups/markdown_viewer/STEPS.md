# Steps

This folder: HTML to open, Python to bake notes, `md_uploaded/` for the files.

**View:** double-click `markdown_folder_viewer.html`. It keeps the last bake.

**After edits:** `python3 embed_markdown_folder.py` then open the HTML again.

**Names:** `01_MBS`, `01_mbs_glossary.md` on disk. Viewer shows spaces.

**New project:** copy this folder, put notes in `md_uploaded/`, bake, open the HTML.

**New notes via Cursor:** paste `CURSOR_AGENT_PROMPT.md`.
